Personal Expense Analyzer
 📌 About the Project
Personal Expense Analyzer is a simple and responsive web application developed using HTML, CSS, and JavaScript. It helps users track their income, manage daily expenses, calculate their remaining balance, and understand their spending habits through visual charts.

 ✨ Features
- Add income and expense transactions
- Calculate total income, expenses, and balance automatically
- Categorize expenses such as Food, Travel, Shopping, and Education
- View spending breakdown using charts
- Filter transactions by income and expenses
- Delete transactions when needed
- Save transaction data using browser LocalStorage
- Responsive design for desktop and mobile devices

 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add transactions and explore the dashboard.

**Note:** An internet connection is required to load the Chart.js library.

📂 Project Structure
- `index.html` – Website structure
- `style.css` – Styling and responsive design
- `script.js` – Transaction management, calculations, and charts

🎯 Project Objective
The main objective of this project is to develop practical web development skills and provide a simple tool for managing personal finances.
